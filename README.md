# Gilded Rose — Modernização de Sistema Legado

Refatoração do sistema Gilded Rose aplicando **SOLID**, **Clean Architecture**, **testes automatizados** e adicionando suporte a **itens Conjurados**.

## Estrutura

```
src/          → código-fonte
tests/        → testes automatizados (pytest)
docs/         → documentação do projeto
apresentacao/ → slides da apresentação final
```

## Execução

```bash
pip install -r requirements.txt
python -m src.main
pytest -v
```
